# SUBSCRIPTION BILLING API EXAMPLES
# Base URL is typically http://10.30.0.61:5005 (Check your environment config, or run `npm run dev`)

# ==========================================
# 1. Create a New Subscription
# ==========================================
# This endpoint creates a new subscription for a customer and charges their wallet.
curl -X POST http://10.30.0.61:5005/api/subscriptions \
  -H "Content-Type: application/json" \
  -d '{
    "customer_id": "C-12345",
    "plan_id": "PLAN-PRO-01",
    "status": "active",
    "addons": [
      {
        "addon_id": "ADDON-DID-LOCAL",
        "quantity": 2
      }
    ]
  }'

# ==========================================
# 2. Get All Subscriptions
# ==========================================
# Retrieves a list of all active and past subscriptions in the system.
curl -X GET http://10.30.0.61:5005/api/subscriptions

# ==========================================
# 3. Get Subscriptions by Customer ID
# ==========================================
# Retrieves all subscriptions for a specific customer.
curl -X GET http://10.30.0.61:5005/api/subscriptions/customer/C-12345

# ==========================================
# 4. Get a Single Subscription
# ==========================================
# Fetches details of a specific subscription. Replace the ID with the UUID or SUB-XXXX ID.
curl -X GET http://10.30.0.61:5005/api/subscriptions/SUB-2601

# ==========================================
# 5. Cancel a Subscription (Professional Teardown & Refund)
# ==========================================
# This triggers the robust cancellation logic:
# - Changes status to "cancelled"
# - Calculates and issues a prorated refund to the customer's wallet
# - Broadcasts a "subscription.cancelled" event
# - The AssetService automatically catches the event and tears down all phone numbers, extensions, etc.
curl -X DELETE http://10.30.0.61:5005/api/subscriptions/SUB-2601

# ==========================================
# 6. Update a Subscription (Manual Override)
# ==========================================
# Manually update fields like next_billing or status without triggering the full cancellation tear-down.
curl -X PUT http://10.30.0.61:5005/api/subscriptions/SUB-2601 \
  -H "Content-Type: application/json" \
  -d '{
    "status": "active",
    "next_billing": "2026-12-01T00:00:00.000Z"
  }'

# ========================================================
# 7. Manually Renew a Specific Subscription
# ========================================================
# Use this to instantly reactivate a suspended or overdue subscription. 
# This endpoint:
# - Charges the customer's wallet for the plan + recurring addons.
# - Updates the next_billing date to the next cycle.
# - Automatically switches all assets (DIDs/Extensions) from 'inactive' back to 'active'.
# Replace the ID with your UUID or SUB-XXXX ID.
curl -X POST http://10.30.0.61:5005/api/subscriptions/SUB-2601/renew
